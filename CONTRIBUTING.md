# Contributing

Read the noncommercial [license](LICENSE) before using or contributing code.
Contributions are offered under that same license. Dependencies and model assets
retain their own terms; do not copy third-party code or weights without the
required notices and permission.

Keep runtime data under ignored `data/`. Never commit books, generated audio,
real voice references, keys, tokens, signing material, or listening history.
Use original synthetic scenes and fake providers in tests. Describe setup changes
in the relevant guide and run the checks in [Development](docs/development.md).

Open an issue with your OS, Node/Docker versions, command, and redacted error.
Exclude credentials, source chapters, personal logs, and private request bodies.
