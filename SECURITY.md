# Security

Do not post credentials, private book text, or user state in public issues.
For a security report, use GitHub's private vulnerability reporting when enabled
on this repository. Include a minimal synthetic reproduction and affected commit.

The default deployment is single-household and loopback-only. Configure HTTPS
before allowing remote access. Provider credentials belong only to generation
processes. Keep state backups private, patch dependencies, and revoke paired
device grants when retiring a device.
