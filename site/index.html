03 / Make it yours

Your next
chapter starts here.

Run Storyteller on your computer or server. The bundled sample gets you listening before you set up a voice engine.

Have Git, Node.js 22.13+, and Docker Compose ready. On Windows, use WSL2 for these commands.

Full setup guide ↗
Start with the sample
git clone https://github.com/benbernard/storyteller.git
cd storyteller
node scripts/setup.mjs
docker compose build listener
docker compose run --rm sample
docker compose up -d --wait listener

Open localhost:8080/listen/. Sign in as listener with the password in data/credentials/listener-password.
