# Changes

## 0.1.0

Initial standalone package of chapter downloads, the audiobook engine, local Mac
speech tools, and Listener for the web and Android. Adds portable Compose setup,
a private household login, configurable Android server URLs, an original silent
demo, setup and maintenance guides, and GitHub Actions checks.

Released under PolyForm Noncommercial 1.0.0. Runtime libraries, private deployment
configuration, user data, and original signing/update infrastructure are excluded.
